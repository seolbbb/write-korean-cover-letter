# 문항별 판단 구조

이 문서는 새 답변을 쓰거나 기존 답변의 구조를 크게 바꿀 때 사용한다. 문항과 가장 가까운 유형을 고르고, 평가 의도와 증거 흐름만 적용한다. 아래 순서를 고정 문장 틀로 복사하거나 사실에 없는 단계로 채우지 않는다.

여러 요구가 결합된 문항은 하위 질문을 먼저 분리한다. 각 하위 질문에 필요한 유형을 연결하되 한 답변의 중심 메시지는 하나로 유지한다. 현재 공고가 별도 형식을 지시하면 그 형식이 우선한다.

## 1. 지원동기

### 평가 의도

왜 이 직무를 계속하려는지, 왜 이 회사의 실제 환경이 그 목표와 맞는지, 이미 어떤 준비를 했는지 확인한다.

### 증거 흐름

`경험에서 생긴 문제의식 → 계속하고 싶은 일 → 회사의 실제 업무·제품·고객·기술환경 → 준비를 보여 주는 경험 → 입사 후 맡고 싶은 구체 과업`

회사 사실은 지원자의 기준과 경험을 연결하는 데 필요한 만큼만 사용한다. 지원자가 실제로 경험하지 않은 고객 문제나 내부 업무 방식은 가설 또는 확인 계획으로 구분한다.

### 피할 실패 패턴

- 회사 명성·성장성·복지·업계 순위만으로 시작한다.
- 홈페이지의 비전과 표현을 길게 복사한다.
- 다른 회사 이름으로 바꿔도 그대로 성립한다.
- 준비 증거 없이 하고 싶은 일과 포부만 제시한다.

## 2. 직무역량·전문성

### 평가 의도

목표 직무의 실제 과업과 가까운 지식·기술·판단을 어떻게 쌓고 검증했는지 확인한다.

### 증거 흐름

`직무 과업에 필요한 역량 정의 → 가장 가까운 문제와 본인 역할 → 방법 선택 이유 → 구체 행동 → 수치 또는 비수치 검증 결과 → 같은 역량의 재현 범위`

학습 과정은 과목·자격·기술 이름의 목록이 아니라 실제 문제에 적용하고 결과를 확인한 장면으로 증명한다.

### 피할 실패 패턴

- 수업·자격·스택을 나열하고 무엇을 만들거나 판단했는지 쓰지 않는다.
- 도구의 난도나 유명세를 전문성의 근거로 삼는다.
- 팀 결과를 개인의 전문성으로 단독 귀속한다.
- 경험하지 않은 직무 과업을 이미 할 수 있는 것처럼 단정한다.

## 3. 문제해결·도전

### 평가 의도

목표와 장애를 어떻게 정의하고 원인을 좁혀 적절한 방법을 선택·검증했는지 확인한다.

### 증거 흐름

`목표와 기준선 → 장애와 영향 → 관찰·측정 → 원인 가설 또는 대안 비교 → 방법 선택과 실행 → 결과와 적용 범위 → 다음에 재사용할 점검 방식`

첫 접근의 실패나 방향 전환은 실제로 있었을 때만 넣는다. 도전은 난도나 고생의 크기보다 판단과 검증으로 보여 준다.

### 피할 실패 패턴

- 처음부터 모든 것을 알고 성공한 영웅담으로 쓴다.
- 야근·끈기·노력의 양으로 해결 과정을 대신한다.
- 도구를 바꿨다는 사실만 있고 선택 이유가 없다.
- 결과 수치의 기준선·범위·측정 조건을 설명할 수 없다.

## 4. 협업·갈등

### 평가 의도

공동 목표 아래 서로 다른 이해관계와 제약을 파악하고, 본인이 어떤 조정 행동으로 공동 결과에 기여했는지 확인한다.

### 증거 흐름

`공동 목표 → 관계와 서로 다른 제약 → 상대 관점 확인 → 공통 기준 설정 → 대안 비교·역할 재설계·정보 공유 → 공동 결과 → 이후 적용하는 협업 원칙`

팀 성과와 본인의 기여를 분리한다. 양보나 설득 자체보다 상대가 참여할 수 있게 만든 구조와 판단 기준을 밝힌다.

### 피할 실패 패턴

- 상대를 무능하거나 비협조적인 사람으로 묘사한다.
- 갈등 원인과 조정 메커니즘 없이 `소통으로 해결했다`고 쓴다.
- 팀의 성공을 본인 단독 성과로 바꾼다.
- `내가 양보했다` 또는 친화력 선언만으로 끝낸다.

## 5. 실패·약점

### 평가 의도

실제 업무나 협업에 영향을 준 약점을 인식하고, 이를 관리하는 행동 체계와 현재 변화를 확인한다.

### 증거 흐름

`반복되는 약점 또는 실패 → 실제 영향 → 원인 인식 → 만든 루틴·도구·피드백 방식 → 확인된 변화 → 남은 위험과 관리법`

약점이 완전히 사라졌다고 과장하지 않는다. 직무 수행 자체를 불가능하게 하는 결함은 다른 사실로 대체하지 말고 소재 적합성을 다시 검토한다.

### 피할 실패 패턴

- 완벽주의처럼 장점으로 쉽게 뒤집히는 표현만 제시한다.
- 영향이나 사례 없이 성격 형용사만 쓴다.
- `앞으로 고치겠다`고 말하고 현재 행동을 제시하지 않는다.
- 작은 실수를 거대한 실패처럼 과장한다.

## 6. 성장과정·가치관

### 평가 의도

현재의 판단 기준이 어떻게 형성됐고 이후 행동에서 일관되게 나타나는지 확인한다.

### 증거 흐름

`현재의 가치·행동 원칙 → 형성 또는 수정된 사건 → 이후 다른 상황에서 반복된 행동 → 현재 선택과 직무에서의 의미`

가치관은 명언이나 자기평가가 아니라 반복된 선택으로 증명한다. 가족·학교의 연대기는 현재 행동을 이해하는 데 필요한 장면만 남긴다.

### 피할 실패 패턴

- 어린 시절부터 현재까지 사건을 연대기식으로 나열한다.
- 명언·좌우명·해시태그가 실제 행동을 대신한다.
- 한 번의 사건에서 평생의 가치관을 과도하게 일반화한다.
- 본문과 무관한 직무 포부를 마지막에 붙인다.

## 7. 입사 후 계획

### 평가 의도

직무의 실제 초기 과업을 이해하고, 현재 준비를 바탕으로 학습과 책임 범위를 현실적으로 확장할 수 있는지 확인한다.

### 증거 흐름

`직무의 실제 초기 과업 → 단기 학습·점검·산출물 → 중기 책임 범위와 성과 기준 → 장기적으로 풀고 싶은 문제 → 지금 가진 준비 증거`

회사의 공개 자료로 확인할 수 없는 내부 절차·조직 계획·승진 시점을 아는 것처럼 쓰지 않는다. 단계는 연차보다 업무 범위와 검증 기준으로 구분한다.

### 피할 실패 패턴

- 직급·연차와 `전문가·리더`라는 목표만 나열한다.
- 현재 준비나 초기 행동 없이 장기 비전부터 말한다.
- 지원 직무 밖의 조직 전략을 확정적으로 제안한다.
- 모든 회사에 적용되는 학습·성장 포부로 끝낸다.

## 8. 시사·산업 이슈

### 평가 의도

현재 이슈를 정확한 범위와 근거로 이해하고, 상반된 관점과 현실적 제약을 고려해 직무 관점의 대응을 제시하는지 확인한다.

### 증거 흐름

`이슈의 범위와 기준 시점 → 공식 자료·원문 근거 → 본인의 입장 → 반대 관점과 트레이드오프 → 회사·직무가 취할 수 있는 현실적 대응`

최신성이 중요한 사실은 현재 자료를 조사하고 출처를 남긴다. 거대한 산업 전망보다 지원 직무가 실제로 판단하거나 실행할 수 있는 범위로 좁힌다.

### 피할 실패 패턴

- 뉴스 내용을 요약하고 본인의 판단을 남기지 않는다.
- 근거 없이 무조건 찬성하거나 반대한다.
- 반대 관점·비용·규제·운영 제약을 무시한다.
- 회사 사업과 직무에서 통제할 수 없는 거대 담론으로 끝낸다.
