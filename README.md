# write-korean-cover-letter

> **AI와 함께 쓰는 자기소개서, 고쳐도 고쳐도 끝이 없나요?**
>
> 무한 수정에 지쳐서 만들었습니다. 환각, AI 특유의 말투, 문항과 맞지 않는 경험, 직무기술서를 옮겨 적은 듯한 지원동기, 읽는 사람보다 키워드만 앞세운 글, 여러 답변에 반복되는 같은 이야기부터 잡습니다.

이 Skill을 설치한 다음 **자기소개서에 쓸 경험, 이전 지원서, 포트폴리오를 정리해 둔 폴더에서 에이전트를 실행하세요.** 공고와 문항을 건네면 폴더의 자료부터 읽고, 어떤 경험을 어느 문항에 쓸지 정한 뒤 초안을 작성합니다.

**분석 근거:** 잡코리아·링커리어에서 합격 사례로 공개된 자기소개서 223건을 AI와 함께 구조 중심으로 살폈습니다. 이 가운데 73개 답변은 질문에 제대로 답했는지, 지원자가 어떤 판단을 내리고 무엇을 했는지, 결과와 직무 연결이 있는지를 같은 항목으로 비교했습니다. 고용24·NCS 공정채용 자료·공공기관 평가표도 함께 확인했습니다.

첫 요청은 이 정도면 충분합니다.

```text
write-korean-cover-letter Skill을 사용해 이 폴더의 경험 자료를 먼저 읽어줘.
```

## 이 Skill이 하는 일

### 1. 폴더의 경험 자료부터 읽습니다

사용자가 매번 경력과 프로젝트를 다시 붙여 넣지 않아도 됩니다. 경험 메모, 이전 지원서, 포트폴리오, 프로젝트 기록을 읽고 사용할 수 있는 사실과 아직 확인되지 않은 내용을 나눕니다.

### 2. 공고와 문항의 제출 조건을 먼저 잠급니다

현재 문항, 하위 질문, 글자 수, 제출 형식, 블라인드 지침을 가장 높은 규칙으로 둡니다. STAR나 두괄식 같은 일반론이 공고와 충돌하면 공고를 따릅니다.

### 3. 문항마다 가장 가까운 경험을 고릅니다

화려한 경험보다 실제 직무에서 풀 문제와 가까운 경험을 찾습니다. 해결한 문제, 사용한 정보와 도구, 협업한 사람, 결과를 판단한 기준을 비교합니다. 여러 문항에 같은 경험이 반복되지 않도록 전체 답변의 소재를 먼저 배분합니다.

### 4. 환각을 막는 사실 장부를 만듭니다

본인의 행동, 타인의 행동, 팀 결과, 수치의 기준과 범위를 분리합니다. 기록이 충돌하면 하나를 골라 쓰지 않습니다. 확인 전에는 빼거나 공통으로 성립하는 표현으로 낮춥니다.

### 5. 질문 유형에 따라 필요한 근거를 바꿉니다

지원동기, 직무역량, 문제해결, 협업·갈등, 실패·약점, 성장·가치관, 입사 후 계획, 산업 이슈의 8개 유형을 구분합니다. 질문마다 평가자가 확인하려는 내용과 필요한 증거가 다르므로 같은 STAR 틀을 모든 답변에 강요하지 않습니다.

### 6. 직무기술서를 복사하지 않고 경험과 연결합니다

공고의 역량 단어를 그대로 붙이지 않습니다. 경험에서 실제로 검증된 판단 방식과 문제 해결 절차를 입사 후 맡을 업무 단계에 연결합니다. 회사 이름만 바꿔도 성립하는 지원동기는 다시 씁니다.

### 7. 읽는 사람을 고려해 문장을 정리합니다

`질문에 대한 답 → 필요한 맥락 → 판단 → 행동 → 결과 → 직무 전이`를 확인합니다. 고정 문장 템플릿이 아니라 누락 점검표로만 사용합니다.

사실과 구조가 정해진 뒤에만 문체를 다듬습니다. 추상적인 포부, 명사 나열, 과한 수식, 반복되는 종결, 번역투와 AI식 상투어를 줄입니다. 자연스럽게 보이려고 새로운 성과나 교훈을 만들지는 않습니다.

### 8. 제출 전 전체 답변을 함께 검사합니다

글자 수와 지정 형식, 회사·직무명, 블라인드 위반, 편집 흔적, 문항 간 경험 중복을 확인합니다. 면접에서 설명하기 어려운 주장이나 출처를 방어할 수 없는 수치는 제출본에서 제외합니다.

## 사용 예시

### 새 답변 작성

```text
이 폴더의 경험 자료와 이전 지원서를 먼저 읽어줘.
아래 공고의 문항별 요구사항을 나누고 각 문항에 쓸 경험이 겹치지 않게 배분해줘.
선정 이유를 설명한 다음 초안을 작성하고 확인이 필요한 사실은 제출문과 분리해줘.
```

### 기존 자기소개서 검토

```text
$write-korean-cover-letter로 이 자기소개서를 검토해줘.
문항 적합성, 본인 기여, 수치 범위, 문항 간 경험 중복부터 확인하고
내용 검증이 끝난 뒤에만 문체를 다듬어줘.
```

### 사실과 수치만 감사

```text
$write-korean-cover-letter를 사용해 제출본의 사실 장부를 만들어줘.
내 행동, 팀 결과, 타인의 판단, 충돌하는 수치와 면접에서 확인할 항목을
분리하고 아직 확인되지 않은 문장은 다시 쓰지 마.
```

## 한계와 원칙

- 공개 합격 사례에는 탈락 비교군이 없어 특정 표현의 합격 효과를 증명할 수 없습니다.
- “합격”이 서류, 인턴, 최종 합격 중 어느 단계인지 불명확한 사례가 있습니다.
- 현재 지원 공고와 평가 기준이 이 저장소의 모든 일반 원칙보다 우선합니다.
- 이 Skill은 합격을 보장하지 않으며, 사용자는 제출 전 사실과 글자 수를 직접 확인해야 합니다.
- 표본 구성과 비교 항목은 [분석 방법과 해석 범위](docs/METHODOLOGY.md)에 공개했습니다.
